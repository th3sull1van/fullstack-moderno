# Checklist — Revisão Pedagógica

Revisor pedagógico: confere que **o leitor aprende de verdade**, na ordem
certa, com dificuldade progressiva.

## Estrutura do capítulo
- [ ] Objetivos claros e verificáveis ("você será capaz de...");
- [ ] Um conceito por vez; pré-requisitos respeitados (ordem linear do sumário);
- [ ] Analogia/contexto antes da teoria densa;
- [ ] Exemplo prático logo após cada conceito novo;
- [ ] Projeto do capítulo com critérios de aceite mensuráveis;
- [ ] Exercícios em 3 níveis: fixação → desafio → sênior;
- [ ] Resumo ao final (reforço dos pontos-chave).

## Qualidade da explicação
- [ ] Linguagem acessível a iniciante, sem jargão sem explicação;
- [ ] Termos técnicos em inglês com explicação em pt-BR na primeira ocorrência;
- [ ] Diagramas/metáforas consistentes com o resto do livro;
- [ ] Armadilhas comuns cobrem os erros reais de quem aprende;
- [ ] Nenhuma seção pula etapas ("é óbvio que...");

## Progressão geral
- [ ] Partes I–VI formam uma linha: fundamentos → frontend → backend → integração → avançado → carreira;
- [ ] Nível de dificuldade cresce de forma sustentável (sem saltos);
- [ ] Cada projeto reutiliza o aprendizado anterior sem depender dele (independentes, por decisão editorial);
- [ ] Exercícios sênior realmente exigem análise/trade-offs (não são só "mais do mesmo").

## Relatório
- [ ] Para cada achado: capítulo, seção, severidade, correção sugerida.
