\section{Política de atualização}

\begin{itemize}[leftmargin=*, itemsep=0.4em]
  \item \textbf{Revisão trimestral}: reconsultar as documentações oficiais e
  atualizar versões, datas e trechos afetados;
  \item \textbf{Regra de quebra}: quando uma versão \emph{quebra} um exemplo
  (API removida, sintaxe nova), o exemplo é atualizado e a mudança registrada
  neste apêndice com data;
  \item \textbf{Regra de manutenção}: cada seção cita a versão usada; o
  repositório \texttt{codigo/} é a fonte de verdade dos exemplos (o livro
  apenas os referencia via \texttt{\textbackslash lstinputlisting});
  \item \textbf{Feedback}: correções e sugestões entram pelo repositório
  (issues/PRs) — veja o apêndice~\ref{apendice:revisao}.
\end{itemize}
