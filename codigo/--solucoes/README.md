# Soluções dos Exercícios

Gabaritos comentados dos **exercícios de fixação** de todos os 25 capítulos,
organizados por capítulo: `cap01/`, `cap02/`, … `cap25/` — um arquivo
`solucoes-capNN.md` por capítulo.

## Como usar (regras de ouro)

1. **Tente primeiro sozinho** — a solução só ensina depois que você tentou (e
   errou). O erro é parte do aprendizado;
2. **Compare, não copie** — leia a solução, feche o arquivo e reescreva do
   seu jeito;
3. **Rode o código** — as respostas com código são executáveis; testá-las
   fixa o aprendizado muito mais do que lê-las;
4. **Use como rubrica** — os critérios de aceite dos projetos (README de cada
   `capNN/`) funcionam como checklist de autoavaliação.

## Cobertura

| Diretório | Capítulo |
|---|---|
| `cap01/` … `cap25/` | Exercícios de fixação (todos os 25 capítulos) |

Os **desafios** e os **exercícios de nível sênior** não têm gabarito aqui de
propósito: são projetos abertos — a verificação é o código rodando (testes)
e os critérios de aceite dos projetos. Se quiser comparar uma solução sênior,
abra uma discussão no repositório.

## Estrutura de cada arquivo

```markdown
# Soluções — Capítulo N: <título>
## Exercício 1 — <enunciado resumido>
<resposta comentada, com código executável quando aplicável>
```
