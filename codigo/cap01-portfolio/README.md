# cap01-portfolio — Meu primeiro site no GitHub Pages

Projeto do Capítulo 1 do livro **Full Stack Moderno**.

## Como executar localmente

```bash
npx serve .
```

Abra http://localhost:3000 (ou a porta indicada).

## Como publicar no GitHub Pages

1. Crie um repositório público chamado `SEUUSUARIO.github.io`.
2. Suba estes arquivos para a branch `main`.
3. Aguarde ~1 minuto e acesse `https://SEUUSUARIO.github.io`.

## Critérios de aceite (checklist do capítulo)

- [ ] Página acessível em `https://SEUUSUARIO.github.io`
- [ ] Título, apresentação, habilidades e contato
- [ ] HTML semântico válido (validator.w3.org)
- [ ] Estilo com cores, espaçamento e responsividade básica
- [ ] Publicada via GitHub Pages
