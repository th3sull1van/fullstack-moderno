# cap25-carreira — Templates de portfólio e plano de carreira

Modelos prontos do projeto do capítulo 25. Copie, preencha com a **sua**
história e use como base do seu portfólio público.

## Arquivos

| Arquivo | Para quê |
|---|---|
| `curriculo-modelo.md` | Currículo de 1 página focado em **impacto com métricas** |
| `readme-portfolio-modelo.md` | O README profissional que todo projeto do portfólio deve ter |
| `plano-12-meses.md` | Plano de carreira: metas trimestrais, stack, ritmo de estudo |
| `perguntas-star.md` | 5 respostas STAR prontas para as perguntas comportamentais mais comuns |

## Regra de ouro (do capítulo)

> Se um recrutador abrir seu repositório às 23h, ele entende o projeto em
> 5 minutos? O README responde (problema, arquitetura, como rodar), os testes
> provam (roda e passa), o deploy demonstra (está no ar). Se faltar uma das
> três, o projeto não está pronto para o mercado.
